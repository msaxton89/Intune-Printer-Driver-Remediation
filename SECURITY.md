# Security and privacy notes

This repository is a sanitised portfolio example.

It intentionally contains no:

- organisation names;
- internal domains;
- IP addresses;
- tenant IDs;
- real certificate thumbprints;
- usernames;
- device inventories;
- production printer models;
- credentials or secrets.

If adapting this project for a real environment, do not commit secrets, private certificates, production exports or organisation-specific identifiers to a public repository.
